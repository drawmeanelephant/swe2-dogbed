SWE-1.7: HARNESS-NATIVE

July 8, 2026. The crossover point: a model trained directly inside the Devin agent harness, on tasks long enough that a single rollout blows past the context window. SWE-1.7 was the lab's first claim to frontier-level intelligence — at a fraction of frontier-level cost.

TRAINED WHERE IT WORKS

Every SWE model before this one was trained for a harness. SWE-1.7 was trained inside one. The Devin agent loop — plan, act, observe, retry — became the RL environment itself, which is a different claim than ‘evaluated in Devin’: the gradient went through the real thing.

THE TWO PROBLEMS LONG-HORIZON RL BRINGS

  • Context exhaustion — Devin tasks run long enough that rollouts exceed the raw context window; training had to teach the model to work beyond what it can literally see.
  • Reasoning bloat — RL on reasoning tasks tends to inflate response lengths (the DeepSeek R1 effect). SWE-1.7 was trained to elaborate only when the task is hard, keeping routine work cheap.
