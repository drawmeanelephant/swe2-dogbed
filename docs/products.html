MUSEUM OF PRODUCTS

Not everything Cognition ships is a headline. This wing holds the side quests, the internal tools that escaped the building, and the small specialized models that never trend on launch day but run inside every Devin session.

EXHIBIT A — DEEPWIKI

April 2025. Cognition noticed something funny: humans kept reading the documentation Devin wrote for itself to navigate codebases. So they industrialized it. DeepWiki generates a continuously-updated, interactive wiki — diagrams, architecture notes, Q&A — for every public GitHub repository, free. Point it at a repo, get the museum tour.

  • May 22, 2025 — the DeepWiki MCP server ships: codebase context and answers about any public repo, served to any MCP client in seconds.
  • The private-repo siblings, Devin Wiki and Devin Search, do the same trick inside enterprises — plus research-mode deep dives into your own code.

EXHIBIT B — KEVIN-32B

Mid-2025. Cognition’s first open-weights model is a 32B-parameter specialist named Kevin — literally K(ernel D)evin — trained with multi-turn RL to write and refine CUDA kernels. The niche is the point: kernel work is iterative, machine-checkable, and has a verifiable reward (correctness × speedup), making it a perfect RL playground.

metric kevin-32b baseline
correctness (KernelBench) 82% 56% (QwQ-32B base)
dataset solved @ 8 refinements 89% o4-mini 53% · o3 51%
best@16 speedup vs PyTorch eager 1.41x o4-mini 0.78x

The technique that mattered more than the weights: masking model thoughts across turns so context doesn’t explode, and letting the environment’s compiler feedback drive refinement. It shipped on Hugging Face and lives on as a research artifact — the first public proof that Cognition’s RL recipe works.

EXHIBIT C — THE INVISIBLE MODELS

The model picker shows the flagship. Under the floorboards run the specialists:

  • swe-grep — released October 16, 2025. An agentic model trained purely for rapid context engineering: find the right files, fast. Powers Fast Context.
  • swe-check — powers Quick Review: a fast, lightweight pass over diffs, optimized for the common ways code goes wrong.
  • SWE-1-mini — the latency-constrained predictor inside Tab; guesses your next action before you make it. Covered in the SWE-1 exhibit.

EXHIBIT D — THE CONNECTIVE TISSUE

  • Devin API — sessions, tasks, file uploads, results. The GA subscription shipped with it in December 2024; it turned Devin from a product into infrastructure.
  • IDE extensions — Devin inside VS Code et al. for teams that never open the web app.
  • Ask Devin — codebase Q&A as a feature, the free-sample version of Search.
  • Playbooks / Snapshots / Secrets / Knowledge — the ops layer that makes an agent repeatable instead of lucky.

EXHIBIT E — THE LABELS ON THE BOTTLE CHANGE

The current menu, as archived: Devin Web, Devin Desktop, Devin CLI, Fusion, plus DeepWiki as the free public outpost. The museum updates when the company does; the date on the placard is October 2026.
